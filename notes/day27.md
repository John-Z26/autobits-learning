## 5. 递归入门（P5739 阶乘）

### 两个必备要素
1. **终止条件**：`if n <= 1: return 1`
   不加就无限往下调，直到 RecursionError
2. **自己调自己**：`return n * fact(n - 1)`

### "递"和"归"是两个方向（这条最该记）
fact(5) = 5 * fact(4)
        = 5 * (4 * fact(3))
        = 5 * (4 * (3 * fact(2)))
        = 5 * (4 * (3 * (2 * fact(1))))
        = 120

递：5→4→3→2→1，一层层压栈（往下）
归：1→2→6→24→120，一层层返回算结果（往上）

### 两个坑
- Python 默认递归上限 **1000 层**，超了报 RecursionError

### 和回溯的关系
回溯 = 递归 + 返回前把刚才做的标记擦掉
