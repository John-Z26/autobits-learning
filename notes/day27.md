```python

```

## 3.Linux部分命令补充
- ss -lntp → 看哪些端口在监听、被哪个进程占（0.0.0.0 外部可访问，127.0.0.1 只听本机）
- top → 实时看 CPU/内存和进程列表
- df -h → 看磁盘各分区剩余空间
- free -h → 看内存，重点看 available 不看 free
