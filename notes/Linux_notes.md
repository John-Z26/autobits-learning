## 一、基础：目录结构与命令格式

### 1.1 Linux 的目录结构

Linux 的目录结构是一个**树型结构**。

- Windows 系统可以有多个盘符（C 盘、D 盘、E 盘）。
- Linux 没有盘符，只有一个根目录 `/`，所有文件都在它下面。
- 路径的层级关系：
  - Linux 用 `/` 表示
  - Windows 用 `\` 表示

```text
Windows:  D:\data\work\hello.txt
Linux:    /usr/local/hello.txt
          ↑ 根目录
```

- Windows 有多个顶级目录，即各个盘符；Linux 只有一个顶级目录，称为**根目录**。

```text
/test/hello.txt
/itheima.txt
/itast/itheima/hello.txt
```

### 1.2 Linux 命令入门

- **命令行**：即 Linux 终端（Terminal），是一种命令提示符页面。
- **命令**：即 Linux 程序。
- Linux 中，命令有其通用的格式：

```text
command [-options] [parameter]
```

| 组成          | 说明                                 |
| ----------- | ---------------------------------- |
| `command`   | 命令本身                               |
| `-options`  | `[可选，非必填]` 命令的一些选项，可以通过选项控制命令的行为细节 |
| `parameter` | `[可选，非必填]` 命令的参数，多数用于命令的指向目标等      |

> ★ 语法中的 `[]`，表示**可选**的意思。

**示例 1**

```bash
ls -l /home/itheima
```

- `ls` 是命令本身，`-l` 是选项，`/home/itheima` 是参数。
- 意思：以列表的形式，显示 `/home/itheima` 目录内的内容。

**示例 2**

```bash
cp -r test1 test2
```

- `cp` 是命令本身，`-r` 是选项，`test1` 和 `test2` 是参数。
- 意思：复制文件夹 `test1` 成为 `test2`。

### 1.3 ls 命令入门

`ls` 命令的作用是**列出目录下的内容**。

```text
ls [-a -l -h] [Linux路径]
   └ 选项        └ 参数
```

- 当不使用选项和参数、直接用 `ls` 命令本体时，表示：以平铺形式，列出**当前工作目录**下的内容。
- Linux 终端启动时，默认加载当前登录用户的 **HOME 目录**作为工作目录。

### 1.4 HOME 目录

- 每个 Linux 操作用户在 Linux 系统的**个人账户目录**，路径在 `/home/用户名`。
- Windows 系统和 Linux 系统，均设有用户的 HOME 目录。

### 1.5 ls 命令的参数

```bash
ls /          # 查看根目录下的内容
```

- `-a`：表示 `all`，即列出全部文件（包含隐藏的文件/文件夹）。
  - 以 `.` 开头的，表示 Linux 系统的隐藏文件/文件夹；只要以 `.` 开头，就能自动隐藏。
  - 只有通过 `-a` 选项，才能看到这些隐藏的文件（夹）。
- `-l`：表示以列表（竖向排列）的形式展示内容，并展示更多信息。

> ★ 语法中的**选项可以组合使用**：

```bash
ls -l -a
ls -la
ls -al
```

三种写法都一样，表示同时应用 `-l` 和 `-a` 的功能。选项和参数也可以一起使用。

- `-h`：表示以易于阅读的形式列出文件大小，如 K、M、G。

> ★ `-h` 必须搭配 `-l` 一块使用。

## 二、目录与文件操作

### 2.1 cd / pwd 命令

**cd：切换工作目录**

- 当 Linux 终端（命令行）打开时，会默认以用户的 HOME 目录作为工作目录。
- 可通过 `cd` 命令更改当前工作目录。
- `cd` 命令来自英文：**Change Directory**。

```text
cd [Linux路径]
```

- `cd` 命令**无需选项，只有参数**，表示要切换到哪个目录。
- `cd` 命令直接执行、不写参数，表示回到 HOME 目录。

**pwd：查看当前工作目录**

- `pwd`：**Print Work Directory**。
- `pwd` 命令无参数、无选项，直接输入即可。

**问题**：当前工作目录处于 `/home/itheima/Desktop`，现在想退回上一级，如何做？

- 可以直接通过 `cd` 回到 HOME 目录；
- 也可以通过特殊路径符来完成。

### 2.2 特殊路径符

| 符号   | 含义         | 示例                                                   |
| ---- | ---------- | ---------------------------------------------------- |
| `.`  | 表示当前目录     | `cd ./Desktop` 和 `cd Desktop` 效果一致                   |
| `..` | 表示上一级目录    | `cd ..` 切换到上一级，`cd ../..` 切换上两级                      |
| `~`  | 表示 HOME 目录 | `cd ~` 切换到 HOME 目录；`cd ~/Desktop` 切到 HOME 下的 Desktop |

### 2.3 mkdir 命令（Make Directory）

`mkdir` 命令可以创建新的目录（文件夹）。

```text
mkdir [-p] Linux路径
```

- **参数必填**：表示 Linux 路径，即要创建的文件夹的路径，相对路径或绝对路径均可。
- `-p` 选项可选：表示自动创建不存在的父目录，适用于创建连续多层级的目录。

### 2.4 touch 命令（创建文件）

```text
touch Linux路径
```

- `touch` 命令**无选项，参数必填**，表示要创建的文件路径。
- 相对路径、绝对路径、特殊路径符均可以使用。

### 2.5 cat / more 命令（查看文件内容）

```text
cat Linux路径
more Linux路径
```

- `cat`：无选项，参数必填；**直接将内容全部显示出来**。
- `more`：同样查看文件内容，但**支持翻页**，如果文件内容过多，可以一页页展示。

### 2.6 cp / mv / rm 命令

**cp（copy）：复制文件 / 文件夹**

```text
cp [-r] 参数1 参数2
```

- `-r` 可选，用于复制文件夹，表示**递归**。
- 参数 1：表示被复制的文件/文件夹。
- 参数 2：表示要复制去的地方。

**mv（move）：移动文件 / 文件夹**

```text
mv 参数1 参数2
```

- 参数 1（Linux 路径）：表示被移动的文件或文件夹。
- 参数 2（Linux 路径）：表示要移动去的地方；如果目标不存在，则进行**改名**，确保目标存在。

**rm（remove）：删除文件、文件夹**

```text
rm [-r -f] 参数1 参数2 ... 参数N
```

- 同 `cp` 命令，`-r` 用于删除文件夹。
- `-f` 表示 `force`，强制删除（不会弹出确认信息）。
  - 普通用户删除内容不会弹出提示，只有 root 管理员删除内容会有提示；
  - 所以一般用户用不到 `-f` 选项。
- 参数 1、参数 2 … 参数 N：表示要删除的文件（夹）路径，用空格隔开。

### 2.7 通配符 `*`

`rm` 命令支持通配符 `*`，用来做**模糊匹配**。符号 `*` 表示通配符，即匹配任意内容（包含空）。

| 写法       | 含义                 |
| -------- | ------------------ |
| `test*`  | 匹配任何以 `test` 开头的内容 |
| `*test`  | 匹配任何以 `test` 结尾的内容 |
| `*test*` | 匹配任何包含 `test` 的内容  |

## 三、查找、过滤与文本处理

### 3.1 which 命令

可以通过 `which` 命令，查看所使用的一系列命令的**程序文件存放在哪里**。

```text
which 要查找的命令
```

### 3.2 find 命令（搜索指定的文件）

**按文件名查找文件**

```text
find 起始路径 -name "被查找的文件名"
```

> ★ `find` 命令支持通配符 `*`。

**按文件大小查找文件**

```text
find 起始路径 -size +/- n[kMG]
```

- `+`、`-`：表示大于和小于
- `n`：表示大小数字
- `kMG`：表示大小单位，`k`（小写）表示 KB，`M` 表示 MB，`G` 表示 GB

### 3.3 grep / wc 和管道符

**grep：从文件中通过关键字过滤文件行**

```text
grep [-n] 关键字 文件路径
```

- 选项 `-n` 可选，表示在结果中显示匹配的**行号**。
- 参数「关键字」必填，表示过滤的关键字，建议使用 `" "` 包围。
- 参数「文件路径」，可作为**内容输入端口**。

**wc：统计文件的行数、单词数量等**

```text
wc [-c -m -l -w] 文件路径
```

| 选项   | 作用              |
| ---- | --------------- |
| `-c` | 统计 bytes 数量（字节） |
| `-m` | 统计字符数量          |
| `-l` | 统计行数            |
| `-w` | 统计单词数量          |

参数「文件路径」，可作为内容输入端口。

|            |        |
| ---------- | ------ |
| \*\*管道符 \` | \`\*\* |

> 含义：将管道符**左边命令的结果，作为右边命令的输入**。

### 3.4 echo / 反引号 / 重定向符 / tail

**echo：在命令行内输出内容**

```text
echo 输出的内容
```

建议使用 `" "` 包围输出内容。

**反引号 `` ` ``**

```bash
echo `pwd`
```

被 `` ` `` 包围的内容，会被作为**命令执行**，而非普通字符。

**重定向符 `>` 和 `>>`**

| 符号   | 作用                           |
| ---- | ---------------------------- |
| `>`  | 将左侧命令的结果，**覆盖**写入到符号右侧指定的文件中 |
| `>>` | 将左侧命令结果，**追加**写入到符号右侧指定的文件中  |

**tail：查看文件尾部内容，跟踪文件的最新更改**

```text
tail [-f -num] Linux路径
```

- `-f`：表示**持续跟踪**。
- `-num`：表示查看尾部多少行，不填默认 10 行；如 `-6` → 查看 6 行。

## 四、vi 编辑器与权限管理

### 4.1 vi / vim 编辑器（10.27）

- `vi` / `vim` 是 **visual interface** 的简称，是 Linux 中最经典的文本编辑器。
- `vim` 是 `vi` 的加强版本，不仅能编辑文本，而且还有 shell 程序编辑功能。

**三种工作模式**

| 模式                 | 说明              |
| ------------------ | --------------- |
| 命令模式（Command mode） | 所敲的按键，编辑器都理解为命令 |
| 输入模式（Insert，即编辑模式） | 可对文件内容进行自由编辑    |
| 底线命令模式             | 用于文件的保存、退出      |

**语法**

```text
vi  文件路径
vim 文件路径   （推荐）
```

如果文件路径表示的文件不存在，那么此命令会用于**编辑新文件**。

**模式切换流程**

```text
打开文件 → 命令模式
  命令模式 --(i / a / o)--> 输入模式 --(ESC)--> 命令模式
  命令模式 --(:)--> 底线命令模式 --(命令 + 回车)--> 命令模式
  底线命令模式 --(输入 wq)--> 保存并退出
```

### 4.2 root 用户、su 和 exit 命令（10.30）

- 在 Linux 系统中，拥有最大权限的账户名为 **root**（超级管理员）。
- `su` 命令用于**切换账户**（Switch User）：

```text
su [-] 用户名
```

- `-` 可选，表示是否在切换用户后**加载环境变量**，建议加。
- 参数「用户名」表示要切换的用户，可省略，省略表示切换到 root。

> ★ 切换用户后，可以通过 `exit` 命令退回上一个用户，也可用快捷键 `Ctrl + D`。
>
> - 普通用户 → 其他用户：**需要密码**
> - root → 其他用户：**不需要密码**

### 4.3 sudo 命令与 sudo 认证配置

可以用 `sudo` 命令，为普通的命令授权，**临时以 root 身份执行**：

```text
sudo 其它命令
```

但要先为普通用户配置 sudo 认证，才能使用。

**配置 sudo 认证**

1. 切换到 root 用户，执行 `visudo` 命令，会自动通过 vi 编辑器打开 `/etc/sudoers`。
2. 在文件最后添加：

```text
itheima ALL=(ALL) NOPASSWD: ALL
```

> ★ 表示使用 `sudo` 命令时，无需输入密码。

1. 最后用 `wq` 保存。

> ★ 补充（原笔记红/蓝字）：我的 Ubuntu 进入的是 **nano 编辑器**，不能使用 `:wq`，要用 `Ctrl + O` 保存文件、`Ctrl + X` 退出；或直接 `Ctrl + X`，然后在询问中选 `Y` 保存。

### 4.4 用户与用户组

- Linux 系统中可以配置多个用户、多个用户组，用户也可以加入多个组中。
- 关于权限的管控级别有 2 个：
  - 针对**用户**的权限控制
  - 针对**用户组**的权限控制

**用户组管理**

```bash
groupadd 用户组名    # 创建
groupdel 用户组名    # 删除
```

**用户管理：创建用户**

```text
useradd [-g -d] 用户名
```

- `-g`：指定用户的组。不指定 `-g`，会创建同名组并加入；指定 `-g` 需要组已经存在，如已存在同名组，必须使用 `-g`。
- `-d`：指定用户 HOME 路径。不指定时，HOME 目录默认在 `/home/用户名`。

**用户管理：删除用户**

```text
userdel [-r] 用户名
```

- `-r`：删除用户的 HOME 目录；不使用 `-r`，删除用户时 HOME 目录保留。

**查看用户所属组**

```text
id [用户名]
```

不提供用户名则查看自身。

**修改用户所属组**

```bash
usermod -aG 用户组 用户名    # 将指定用户加入指定用户组
```

**getent 命令**

```bash
getent passwd    # 查看当前系统中有哪些用户
getent group     # 查看当前系统中有哪些组
```

`getent passwd` 输出含 7 份信息：

```text
用户名:密码(x):用户ID:组ID:描述信息(无用):HOME目录:执行终端(默认 bash)
```

`getent group` 输出含 3 份信息：

```text
组名称:组认证(显示为 x):组ID
```

> ★ 小结：`groupadd` 添加组、`groupdel` 删除组；`useradd` 添加用户、`userdel` 删除用户；`usermod` 修改用户组、`id` 查看用户信息；`getent passwd` 查看全部用户信息、`getent group` 查看全部组信息。

### 4.5 查看权限控制信息（10.31）

`ls -l` 可以以列表形式查看内容，并显示权限细节。

```text
drwxr-xr-x  3  itheima  itheima
└ 权限细节      └ 所属用户  └ 所属用户组
```

**权限细节共 10 个槽位**：

```text
- 或 d 或 l | r - w - x - | r - w - x - | r - w - x -
  └ 类型        所属用户权限    所属用户组权限    其它用户权限
```

| 首位  | 含义    |
| --- | ----- |
| `-` | 表示文件  |
| `d` | 表示文件夹 |
| `l` | 表示软链接 |

| 权限位          | 含义                                  |
| ------------ | ----------------------------------- |
| `r`（read）    | 读：`ls` 查看文件夹内容、`cat` 查看文件内容等        |
| `w`（write）   | 写：对文件夹可创建、删除、改名；对文件可修改内容            |
| `x`（execute） | 执行：对文件可作为程序执行；对文件夹可用 `cd` 进入、更改工作目录 |

### 4.6 修改权限控制：chmod / chown（11.1）

**chmod 命令**：可修改文件、文件夹的权限信息。

> ★ 注意：只有文件、文件夹的**所属用户**或 **root 用户**才可以修改。

```text
chmod [-R] 权限 文件或文件夹
```

- `-R`：对文件夹内的全部内容应用同样的操作。

**示例**

```bash
chmod u=rwx,g=rx,o=x hello.txt
# 将文件权限修改为 rwxr-x--x，即 751
# u = user，g = group，o = other

chmod -R u=rwx,g=rx,o=x test
# 将文件夹 test 以及文件夹内全部内容权限设置为 rwxr-x--x
```

**权限的数字序号**

```bash
chmod 751 test.txt
```

权限可以用 3 位数字来代表：第一位表示用户权限（user），第二位表示用户组权限（group），第三位表示其它用户权限（other）。

数字细节：`r` 记为 4，`w` 记为 2，`x` 记为 1。

| 数字 | 权限               | 数字 | 权限               |
| -- | ---------------- | -- | ---------------- |
| 0  | 无权限 `---`        | 4  | 有 r 权限 `r--`     |
| 1  | 有 x 权限 `--x`     | 5  | 有 r 和 x 权限 `r-x` |
| 2  | 有 w 权限 `-w-`     | 6  | 有 r 和 w 权限 `rw-` |
| 3  | 有 w 和 x 权限 `-wx` | 7  | 有全部权限 `rwx`      |

`751` 表示：`rwx`(7) + `r-x`(5) + `--x`(1)。

**chown 命令**：修改文件、文件夹的所属用户和用户组。

> ★ 只适用于 **root 用户**。

```text
chown [-R] 用户:用户组 文件或文件夹
```

- 选项 `-R`：同 `chmod`，对文件夹内全部内容应用相同规则。

**示例**

```bash
chown root hello.txt           # 将 hello.txt 所属用户改为 root
chown :root hello.txt          # 将 hello.txt 所属用户组改为 root
chown root:itheima hello.txt   # 所属用户改为 root，用户组改为 itheima
chown -R root test             # 将 test 及文件夹内全部内容所属用户改为 root
```

## 五、网络请求和下载（第四章-8）

### 5.1 ping 命令

检查指定的网络服务器是否可联通。

```text
ping [-c num] ip 或主机名
```

- 选项 `-c`：检查的次数；不使用 `-c` 选项，将**无限次数**检查。
- 结果判断：不通 → `Unreachable`；通 → `time = 87.0ms`。

### 5.2 wget 命令

非交互式的文件下载器，可在命令行内下载网络文件。

```text
wget [-b] url
```

- 选项 `-b`（可选）：后台下载，会将日志写入当前工作目录的 `wget-log` 文件。
- 参数 `url`：下载链接。

> ★ 补充：
>
> - 取消下载：`Ctrl + C`
> - 通过 `tail` 命令监控后台下载进度：`tail -f wget-log`（`-f` 表示持续跟踪）
> - 注意：无论下载是否完成，都会生成要下载的文件。如果下载未完成，请及时用 `rm` 清理未完成的不可用文件。


### 5.3 curl 命令

可以发送 http 网络请求，可用于：下载文件、获取信息等。

```text
curl [-O] url
```

- 选项 `-O`：用于下载文件。当 `url` 是下载链接时，可以使用此选项保存文件。
- 参数 `url`：要发起请求的网络地址。

```bash
curl cip.cc    # 向 cip.cc 发起网络请求，获取主机公网地址
```

## 六、端口（4-9）

端口是设备与外界通讯交流的出入口，可分为**物理端口**和**虚拟端口**两类。

- **物理端口**：又可称为接口，是可见的端口，如 USB 接口、RJ45 网口、HDMI 端口等。
- **虚拟端口**：指计算机内部的端口，是不可见的，用于操作系统和外部交互。
  - IP 只能锁定计算机，无法锁定具体的程序；
  - 通过端口可以锁定计算机上具体的程序，确保程序之间沟通。
  - 类比：IP 相当于小区地址，端口就相当于门牌号，访问对应程序需要端口。

Linux 系统支持 **65535** 个端口，分 3 类使用：

| 分类      | 范围            | 说明                                                  |
| ------- | ------------- | --------------------------------------------------- |
| 1. 公认端口 | 1 ~ 1023      | 通常用于系统内置或知名程序的预留使用，如 SSH 服务的 22 端口、HTTPS 服务的 443 端口 |
| 2. 注册端口 | 1024 ~ 49151  | 可以随意使用，用于松散地绑定一些程序/服务                               |
| 3. 动态端口 | 49152 ~ 65535 | 通常不会固定绑定程序，而是当程序对外进行网络连接时用作临时端口                     |

> ★ 非特殊需要，不要占用公认端口。

**查看端口占用情况**

```bash
yum -y install nmap       # 安装 nmap
nmap 被查看的IP地址
nmap 127.0.0.1            # 查看本机 IP 对外暴露的端口
```

```bash
yum -y install net-tools              # 安装 netstat
netstat -anp | grep 端口号           # 查看指定端口的占用情况（管道符 + grep 过滤）
```

> 补充：`0.0.0.0` 有时也代表本机。

## 七、进程管理（4-10）

程序运行在操作系统中，每个程序在运行时，便被操作系统注册为一个**进程**；每一个进程都分配一个独有的**进程 ID（进程号）**。

### 7.1 查看进程：ps

```text
ps [-e -f]
```

- `-e`：显示出全部的进程
- `-f`：以完全格式化的形式展示信息

> ★ 一般来说，固定用法就是 `ps -ef`，列出全部进程的全部信息。

`ps -ef` 输出字段：

| 字段      | 含义                                  |
| ------- | ----------------------------------- |
| `UID`   | 进程所属用户 ID（user ID）                  |
| `PID`   | 进程 ID（进程号）                          |
| `PPID`  | 进程的父 ID（启动此进程的其它进程的进程号）             |
| `C`     | 此进程 CPU 占用率（%）                      |
| `STIME` | 进程的启动时间                             |
| `TTY`   | 启动此进程的终端序号（`?` 表示非终端、系统启动；其它表示终端启动） |
| `TIME`  | 进程占用 CPU 时间                         |
| `CMD`   | 启动此进程的命令或程序路径（启动命令）                 |

**查看指定进程**（用管道符配合 `grep` 过滤）

```bash
ps -ef | grep 关键字
```

> 不仅过滤名称，进程号、用户 ID 等都可以被 `grep` 过滤。

### 7.2 关闭进程：kill

```text
kill [-9] 进程ID
```

- 选项 `-9`：表示**强制关闭**进程。不使用此选项会向进程发送信号要求关闭，但是否关闭取决于进程自身的处理机制。
- 返回提示：`Terminated` 是主动关闭；`Killed` 是强制关闭。

> ★ 补充：`top` 命令（动态进程）、`ps` 命令（静态快照）。

## 八、环境变量（4-12）

- 使用的一系列命令，本质上就是一个个**可执行程序**。
- 比如 `cd` 命令本体就是 `/usr/bin/cd` 这个程序文件。
- 问题：为何无论当前工作目录在哪，都能执行 `/usr/bin/cd` 这个程序？

**环境变量**：操作系统运行时，记录的一些关键性信息，用以辅助系统运行。

- 在 Linux 中执行 `env` 命令，即可查看当前系统中记录的环境变量。
- 环境变量是一种 **KeyValue** 型结构，即名称和值。

| 变量     | 示例值          | 含义          |
| ------ | ------------ | ----------- |
| `HOME` | `/home/asus` | 用户的 HOME 路径 |
| `PWD`  | `/home/asus` | 当前的工作路径     |
| `USER` | `asus`       | 当前的操作用户     |

### 8.1 PATH

`PATH` 记录了系统执行任何命令的**搜索路径**。

```text
PATH = /usr/local/bin : /usr/bin : /usr/sbin ...
```

当执行任何命令，都会按照顺序，从上述路径中搜索要执行的程序本体。

### 8.2 `$` 符号

在 Linux 中，`$` 符号被用于取「变量」的值。

```bash
echo $PATH        # 取得 PATH 这个环境变量的值，并通过 echo 输出
echo ${PATH}ABC   # 与其它内容混合时，用 {} 标注取的是哪个变量
```

### 8.3 自行设置环境变量

> ★ 可以修改 `PATH` 的值，加入自己的命令搜索路径。

**临时设置**

```text
export 变量名=变量值
export PATH=$PATH:自定义路径
```

**永久生效**

- 针对**当前用户**生效：配置在当前用户的 `~/.bashrc` 文件中。
- 针对**所有用户**生效：配置在系统的 `/etc/profile` 文件中。
- 并通过 `source 配置文件` 立刻生效，或重新登录生效。
