### 2.6.2 json
**常用于:**
- API
- 配置
- 数据交换
```json
{
"name": "AutoBits",
"members": 20
}
```
**注意：**
- Key 通常使用双引号。
- 不支持注释。
- 格式错误会导致解析失败。
### 2.6.3 YAML
**常用于：**
- CI/CD
- Docker Compose
- Kubernetes
- 配置文件
```yaml
app:

```
**注意**
- YAML 对缩进敏感，缩进不能用TAB，只能用空格

### 2.6.6 Base64
- Base64是把二进制数据（图片、文件）转成纯文本的一种编码方式
- 不是<mark>加密</mark>

### 2.6.7 时间与时间戳
- 项目中常见：
- 2026-10-03T20:00:00+08:00或者 Unix Timestamp
- 时间+时区 经常一起出现。
- 不同服务器和用户可能处于不同时区

### 2.6.8 序列化
程序中的对象往往需要转换为：
- JSON
- 字节
- 文件
- 网络数据

这个过程被称为序列化(Serialization)

**序列化(Serialization)就是把内存里的对象，转成可以存文件或网络传输的格式。**

|格式|长什么样|用在哪|
|:--|:--|:--|
|JSON|{"name":"John","age":19}	|最常用，接口传数据
|XML|<user><name>John</name></user>|老系统、配置文件
|二进制|一堆 010101	|性能要求高的场景
|Base64	|SGVsbG8=	|你刚学的，也是一种序列化 / 编码
